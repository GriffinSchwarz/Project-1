# Claude Code mods: the mechanics (from the built-in plugin-authoring skill, Claude Code 2.1.292; the declaration file claude-code.d.ts is the authority; API is early access)

- A mod is a plugin of function hooks: `.claude-plugin/plugin.json` {name, version, description, optional "types": "./types/index.d.ts"}, `hooks/hooks.json` {"modules":["./register.tsx"]}, `hooks/register.tsx` exporting `register(on, options)`. Every hook has the shape `($, e, next)`; `$` is the engine, `e` a frozen value, `next(e)` passes down the chain. Sandbox: no DOM, no Node, no require, no dynamic import(). JSX against `h`; UI elements from `$.ui.resolve(e)`.
- Draw: a Pane (`$.ui.open({id,title})` then `ui.render` on component 'Pane' with requestId = pane id), a band (`ui.render` on 'AbovePrompt'), a status line (`$.ui.status`, one per plugin), a toast (`$.ui.toast`, 4000 ms default). Pane opened by the person seats at any width; opened unasked it needs 144 columns (110 once the person has opened it before); docks from 110 columns in fullscreen. Pane id: 1-64 of letters, digits, _ and -.
- State: `$.state` (session-scoped, survives hot reload; render hooks must never write; refs `atom({plugin:'<name>', key:'<key>'})` with literal strings, typed in types/index.d.ts under `interface PluginState`); `$.store` (JSON across sessions, 4 MiB cap). Module variables are lost on reload. Timers: `$.clock.every/after` started from `session.start`.
- Events: turn.start/step/complete/abort, tool.call/check/describe, agent.spawn/offer, prompt.*, command.run/describe, config.*, session.start/end/append/send/receive/compact/attach/detach/measure, ui.render/resolve/press/input/select/message/fault/scroll/focus, skill.prompt, attribution.text, plugin.register, engine.create, model.complete/classify/fork, audio.*, mcp.call/connect, process.spawn, telemetry.*; plus classic settings hooks as `classic.<Event>` (PreToolUse, PostToolUse, SubagentStart {agent_id, agent_type}, SubagentStop {agent_id, agent_type, agent_transcript_path, last_assistant_message, background_tasks}, TaskCreated/TaskCompleted {task_id, task_subject}, TeammateIdle, SessionStart/End, Stop, PreCompact/PostCompact, Notification, ...).
- Agent data: `$.agent.list()` -> AgentInfo {id, description, type, status: pending|running|waiting|idle|completed|failed|killed, parentId, spawnedBy, name}; `agent.spawn` hook input {tool_use_id, prompt, description, subagentType, model, parentModel, parentAgentId, background, cwd}, `await next(e)` returns {model, agentId}; `tool.call` inside a subagent carries e.agentId (Bash: e.command and description); `turn.complete` carries agentId, answer, durationMs, usage, reason (answer|aborted|refusal|error); `$.session.messages({agentId})` reads one agent's transcript; a background task notification is a UserMessage with e.props.origin.kind === 'task-notification'.
- `$` methods: session.cwd/root/model/turns/id/messages/repo/surface; tool.list/register; command.list/register; agent.list/register/spawn; ui.toast/status/log/notice/invalidate/open/close/panes/selection/copy/blit; fs.read/write/list/exists/stat/ancestors (relative paths under cwd, absolute as given); store.get/set/delete/keys; state.get/set; clock.now/sleep/after/every; http.fetch; process.run (4 MiB stdout cap); settings.read; env.get/set; prompt.read; config.list.
- Limits: toast/status first 2000 chars; a tree draws the first 100,000 chars; Svg 131,072 chars; image 2 MiB; a failing hook is skipped and the chain continues; invalid trees are replaced by the engine's own with a log line; each hook has a time budget; mobile surface has no Input/Select/Client, terminal has no Svg (Raster/Image instead); use Markdown for model-style text.
- Enable: write the mod into the dev-mods folder (the engine asks "Enable hot reloading for this session?"; only the person answers), or `claude --plugin-dir <folder>`, or `CLAUDE_CODE_PLUGIN_DIRS` (process env or ~/.claude/settings.json env, never a project's). Reload = fresh register() and session.start; $.state/$.store persist. Tooling: `claude plugin validate <dir>`, `claude plugin test <dir>` (runs *.test.ts), `tsc -p`, `claude --debug`. Sharing via a marketplace file and `/plugin install <mod> --marketplace <owner>/<repo>`.
- Pane example pattern (tool-calls pane): session.start registers a command and opens the pane; tool.call appends {id, tool, isDone:false} via update($, atom, fn), awaits next(e), marks done; ui.render on {component:'Pane', requestId} reads the atom and returns <Box flexDirection="column"> rows sized to e.viewport.rows.
