# Project-1

A working notebook that lets Claude sessions in the cloud pick up where the local sessions stopped.

| File | What it is |
|---|---|
| `HOW-TO-UPLOAD.md` | Three ways to get files in here, and what must never go in |
| `inbox/` | Drop new files here, then tell Claude "file the inbox" |
| `docs/TRANSFER-TEMPLATE.md` | A short "delta" transfer format, so each handoff is a few KB |
| `tools/reviews_write.py` | Writes REVIEWS.md lines with the clock time, ASCII only, and no stray placeholders (16 tests) |
